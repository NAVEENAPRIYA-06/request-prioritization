# SmartService | Request Prioritization Tool

SmartService is a full-stack dashboard designed for construction and enterprise environments to manage service requests efficiently. It features a robust **Role-Based Access Control (RBAC)** system, allowing admins to manage workflows and employees to track their requests in real-time.

---

## 🚀 Features
* **Role-Based Dashboards**: Separate interfaces for Administrators and Employees.
* **Request Management**: Create, track, and update service requests with varying priority levels.
* **SLA Intelligence**: Live monitoring of service level agreements and deadlines.
* **Audit Intelligence**: Comprehensive logging of system actions for security.
* **Analytics Hub**: Visual performance metrics and system health monitoring.

---

## 🛠️ Tech Stack
* **Frontend**: React.js, Tailwind CSS, Lucide Icons.
* **Backend**: Node.js, Express.js.
* **Database**: MySQL (Managed via phpMyAdmin/XAMPP).
* **State Management**: LocalStorage & React Hooks.
* **API Client**: Axios.
